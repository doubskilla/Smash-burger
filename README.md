# Smash Burger

Prototype front-end statique. Lire DESIGN.md avant toute modification.

## Lancer le site

Depuis la racine du dépôt, exécuter `python3 -m http.server 8000 --directory dist`, puis ouvrir http://localhost:8000.

Les sources HTML, CSS et JavaScript sont directement dans dist/. Les images et polices sont dans dist/assets/. Aucun build nécessaire.

Le DESIGN.md décrit la cible. Les grandes cartes des suppléments, l’harmonisation complète des animations et le parcours de commande restent à finaliser. Les fiches produit actuelles constituent une première base.
